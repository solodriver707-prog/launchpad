# GIGAPAD (beta)

Every legend starts at zero. Launch tokens. Trade against anything.

Tīrs HTML/CSS/JS — bez npm un build soļa. Faili: index.html, styles.css, avatars.js, app.js.

## Kā atjaunināt Netlify
Netlify → tava lapa → Deploys → ievelc šo mapi laukā "Drag and drop your site output folder here".
Saite paliek tā pati.

## Kas ir īsts
- Wallet savienojums (Phantom, Solflare, Backpack…) caur Wallet Standard, Solana devnet
- SOL bilance, "Get 1 devnet SOL", adreses kopēšana, auto-reconnect

## Kas ir simulēts (beta)
- Tokeni, cenas, darījumi, jaunie launchi un tavi "Buy/Sell/Launch" — nekas netiek sūtīts blokķēdē
- Visi logo ir oriģināli, zīmēti avatars.js (nav citu monētu logo)
